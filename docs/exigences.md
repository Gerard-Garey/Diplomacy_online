# Cahier des charges

**À ADAPTER.** Ce document fixe ce que le projet doit faire ; `CLAUDE.md` renvoie ici pour le fond. Chaque exigence est numérotée pour être citée dans les issues, les ADR et les revues (`docs/exigences.md` § 2.3).

## 1. Objet et destinataires

Ce que produit le projet, pour qui, et ce qui prime (traçabilité, performance, délai…).

## 2. Exigences de fond

Méthodes, règles métier, textes de référence et celui qui fait foi ; conditions d'usage (taille d'échantillon, hypothèses) ; niveau de rigueur attendu (distinguer résultat établi, approximation et constat empirique).

## 3. Exigences documentaires

Documentation attendue, format, destinataire ; ce qu'un relecteur externe doit pouvoir y vérifier sans lire le code.

## 4. Exigences d'architecture

Découpage du code, dépendances permises, reproductibilité (graines, références de non-régression, plateforme de référence).

## 5. Interface

Disposition, saisie, restitution, messages d'erreur ; règle « aucun calcul hors du module de calcul ».
